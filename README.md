[Nest](https://github.com/nestjs/nest) framework TypeScript

## Quick Setup
**Pre Reqs: Docker, Docker Compose**
```bash
make start
```

## Cheat Sheet

```bash
# start
make start

# stop
make stop

# reload
make reload

# run migrations
make migrate

# revert last migration
make migrate_revert
```

## Running the app

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```

## Test

```bash
# unit tests
$ npm run test

# e2e tests
$ npm run test:e2e

# test coverage
$ npm run test:cov
```
